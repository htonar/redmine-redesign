# Дизайн-язык

Референс: [Redmine-project management. Redesign concept](https://www.behance.net/gallery/55938021/Redmine-project-management-Redesign-concept)
(Oleksandr Sydorov, Behance). Это визуальное направление, не готовая дизайн-система -
цвета и отступы ниже сняты приблизительно (на глаз со скриншотов), уточнять при верстке.

## Общий лейаут

- Темный **левый sidebar** фиксированной ширины с иконками разделов (без подписей в
  свернутом виде): гамбургер-toggle, профиль, сообщения, time tracker, активность/графики,
  задачи (карандаш), отчеты, цели/фокус, файлы.
- Светлая **рабочая область** справа: белый фон, карточки с мягкой тенью и скруглением.
- **Топ-бар** внутри рабочей области: поиск по центру/слева, справа - переключатель
  проекта ("Go to project"), имя пользователя + аватар.
- Сетка из карточек (dashboard-style): каждая карточка - самостоятельный блок с
  заголовком, может содержать список, график или форму.

## Цветовая палитра (приблизительно)

| Роль | Цвет | Где используется |
|---|---|---|
| Sidebar / темный фон | `#161f38` – `#1b2a4a` (темно-синий, почти navy) | sidebar, hero-блоки, темные секции |
| Бренд-акцент | `#e6362c` – `#ea3f36` (насыщенный красный) | логотип "Redmine", ключевые CTA, важные бейджи |
| Вторичный акцент | `#29c1e0` – `#4fd1e8` (голубой/циан) | графики, progress-бары, ссылки-выделения |
| Фон контента | `#ffffff` / `#f7f8fb` | рабочая область, карточки |
| Текст основной | `#1b2333` (почти черный, не чистый) | заголовки, основной текст |
| Текст вторичный | `#8a93a6` (серо-синий) | подписи, метки, второстепенная инфа |

Уточнить точные HEX по факту - можно снять пипеткой с оригинальных превью на Behance
при верстке конкретных экранов.

## Типографика

- Гротеск (sans-serif), похож на Proxima Nova / Museo Sans - заменяем на
  системный стек или Inter/Manrope как ближайший бесплатный аналог.
- Заголовки - жирные (600–700), крупный кегль на hero/статах (32–48px для чисел
  в stat-карточках).
- Основной текст мелкий, плотный (13–14px), с хорошим line-height в таблицах задач.

## Компоненты, встреченные в макетах

- **Sidebar-иконки** - круглые/квадратные hit-области, активный пункт подсвечен.
- **Аватары** - круглые, с цветным индикатором статуса (точка).
- **Тег-пилюли** - скругленные бейджи с цветной точкой + текст (`• Monobank`, `• Design`).
- **Прогресс/readiness-бар** - горизонтальная полоса с процентом, используется и в
  карточке задачи, и в Gantt.
- **Dropdown с аватарами** - список пользователей с фото при выборе "Assigned to".
- **Stat-карточка** - крупное число, подпись, тренд (стрелка + %, зеленый/красный),
  иногда мини-график или полоса снизу.
- **Line chart** - сглаженная кривая, циановая заливка/линия, сетка по осям.
- **Gantt-бар** - двойная полоса (план темно-синим, факт - светло-синим/циан поверх),
  вертикальная красная линия "сегодня".
- **Day-timeline (календарь)** - блоки-события на временной шкале, цвет по проекту/типу.
- **Карточка задачи (issue)** - двухколоночная: слева описание/детали, справа -
  редактируемые свойства (статус, приоритет, assignee, readiness, spent time) +
  комментарии/notes снизу.
- **Файловый менеджер** - список/грид файлов с папками, кнопки Upload/New document.

## Что взять в реализацию

Идем по плану: **shadcn/ui на Radix Primitives** как база (доступные, безголовые
компоненты - button, dropdown, dialog, avatar, tabs, tooltip, progress), поверх -
своя тема (токены цвета/шрифта из таблицы выше) и кастомные составные компоненты
(stat-карточка, issue-карточка, gantt-бар, sidebar-навигация), которых в shadcn нет
из коробки.

## Статус

Черновая фиксация направления, сделано до начала верстки компонентов. Актуализировать
по мере верстки - если конкретный компонент на практике требует другого цвета/отступа,
поправить таблицу здесь, а не держать расхождение молча.
